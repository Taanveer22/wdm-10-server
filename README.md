# 🌸 Orchid Movie Portal - Server

A RESTful API backend for the **Orchid Movie Portal**, built with Node.js, Express.js, and MongoDB.  
This server handles movie data, user-specific favorites, search functionality, and core CRUD operations for the application.

---

## 🚀 Live Server

👉 Deployed Server: _(https://wdm-10-server.vercel.app/)_

---

## 📄 Project Overview

This backend powers the Orchid Movie Portal frontend by providing APIs for:

- Movie management (CRUD operations)
- User-specific added movies
- Favorites system
- Search functionality
- Featured movies data

It is built with a modular Express architecture and connected to MongoDB for persistent data storage.

---

## ✨ Key Features

### 🎬 Movie Management

- Create new movies
- Read all movies
- Read individual movie details
- Delete movies from collection

---

### ❤️ Favorites System

- Add movies to favorites
- Get all favorite movies
- Get user-specific favorite movies
- Delete favorite movies

---

### 👤 User-Based Data Handling

- Retrieve movies added by individual users
- Filter data per user email

---

### 🔍 Search Functionality

- Backend search API implemented
- Case-insensitive movie search using query params

---

### ⭐ Featured Movies

- API support for featured movie listings

---
